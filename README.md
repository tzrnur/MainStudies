# MainStudies

A collection of code, notes, and mini-projects covering key topics in Industrial Engineering, 
including Optimization, Simulation, Stochastic Models, Operations Research, and Data Analytics.

## 📁 Structure
This repository will be organized into lesson-based modules:

- **scheduling/** → optimization techniques used for machine/task scheduling, including LP/IP models, heuristics, and real-world scheduling examples  
- **operations-research/** → core OR methods such as network models, queueing systems, Markov processes, decision analysis 
- **simulation/** → Monte Carlo simulations, discrete-event simulation models, system performance analysis, and variability-focused studies  
- **production-planning/** → demand analysis, capacity planning, MRP/ERP logic, inventory models, and data-driven production optimization  
- **quality-control/** → statistical quality control, control charts, process capability analysis, and quality-improvement projects  
- **forecasting/** → time series methods, regression-based forecasting, error analysis, and practical forecasting projects  
- **data-science/** → Python fundamentals, data preprocessing, visualization, feature engineering, and introductory machine learning workflows  
- **ai-llm/** → applied AI topics including embeddings, prompt engineering, LLM workflows, and small practical experiments with AI models  

Each folder will include a README that explains its content.

## 🎯 Purpose
- Build a clean portfolio of all studies  
- Track your progress  
- Demonstrate your IE + optimization skills to future employers
